# 🎯 Macro Recorder & Editor

Профессиональный инструмент для записи и воспроизведения макросов мыши и клавиатуры с возможностью экспорта в standalone EXE файлы.

## ✨ Возможности

✅ **Запись действий:**
- Движение мыши с фильтрацией шума
- Нажатия клавиш (все клавиши клавиатуры)
- Клики мыши (левая, правая, средняя кнопки)
- Прокрутка колёсика

✅ **Редактор макросов:**
- DataGrid с редактированием действий
- Перемещение, копирование, удаление действий
- Undo/Redo (Ctrl+Z / Ctrl+Y)
- Вставка задержек

✅ **Глобальные горячие клавиши:**
- Настраиваемые клавиши для Записи, Стопа и Воспроизведения
- Работают в любом окне, даже когда приложение свёрнуто
- Любые клавиши: F1-F12, буквы, цифры, модификаторы

✅ **Экспорт в EXE:**
- Создание автономных .exe файлов из макросов
- Работает без установки .NET и приложения
- Настройки: задержка перед стартом, повторы, скорость, горячая клавиша

✅ **Дополнительно:**
- Темы: Светлая / Тёмная
- Локализация: Русский / English
- Автосохранение макросов
- Скорость воспроизведения (0.5x - 5x)
- Повторы (1, 3, 5, 10, бесконечно)

## 📋 Системные требования

- **ОС:** Windows 10/11 (x64)
- **Память:** 50 МБ свободного места
- **.NET:** Не требуется (встроено в приложение)

##  Как использовать

### Быстрый старт:

1. **Запустите** `MacroRecorder.exe`
2. **Нажмите** "Запись" или горячую клавишу (по умолчанию F9)
3. **Выполните** действия, которые нужно записать
4. **Нажмите** "Стоп" или горячую клавишу (по умолчанию F10)
5. **Нажмите** "Воспроизвести" или горячую клавишу (по умолчанию F11)

### Экспорт макроса в EXE:

1. Запишите макрос
2. Разверните панель **"Настройки экспорта"**
3. Настройте параметры:
   - Задержка перед стартом (мс)
   - Количество повторов
   - Скорость воспроизведения
   - Горячая клавиша запуска
4. Нажмите **"Экспорт в EXE"**
5. Выберите место сохранения
6. Готово! Полученный `.exe` можно запустить на любом ПК

### Горячие клавиши (настраиваемые):

- **Запись:** Нажмите на кнопку "Запись: [клавиша]" → нажмите нужную клавишу
- **Стоп:** Нажмите на кнопку "Стоп: [клавиша]" → нажмите нужную клавишу
- **Play:** Нажмите на кнопку "Play: [клавиша]" → нажмите нужную клавишу

По умолчанию: F9 (запись), F10 (стоп), F11 (воспроизведение)

### Редактирование макроса:

- **Удалить действие:** Выделите строку → Delete или кнопка "Удалить"
- **Копировать:** Ctrl+C
- **Вставить:** Ctrl+V
- **Отменить:** Ctrl+Z
- **Повторить:** Ctrl+Y
- **Переместить:** Кнопки ▲ Вверх / ▼ Вниз
- **Дублировать:** Кнопка "Копия" или правый клик → Дублировать

## 🔧 Настройки

### Скорость и повторы:
- **Скорость:** 0.5x, 1x, 2x, 5x
- **Повторы:** 1, 3, 5, 10, ∞ (бесконечно)

### Темы и язык:
- **Тема:** Светлая / Тёмная (кнопки в верхней панели)
- **Язык:** Русский / English (кнопки в верхней панели)

## ⚠️ Важные замечания

1. **Права администратора:** Для работы глобальных хуков может потребоваться запуск от имени администратора
2. **Антивирус:** Некоторые антивирусы могут блокировать приложение (ложное срабатывание). Добавьте в исключения при необходимости
3. **Экспортированные макросы:** Требуют нажатия горячей клавиши для старта (по умолчанию F9)
